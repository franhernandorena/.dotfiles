# Análisis de Contenido - Linux Dotfiles Config

## Tipo de Contenido
Tutorial/Documentación educativa sobre configuración de dotfiles para Arch Linux.

## Tema Principal
Explicar qué archivos son necesarios y cuáles no en un repositorio de dotfiles para Arch Linux con Hyprland.

## Público Objetivo
Desarrolladores que usan Linux/Arch y quieren organizar sus configuraciones.

## Puntos Clave a Cubrir
1. Qué es un repositorio de dotfiles
2. Componentes esenciales de un setup Arch Linux con Hyprland
3. Window managers y terminals (Hyprland, Ghostty, Kitty)
4. Shells y herramientas (Zsh, Zellij)
5. UI/UX (Waybar, Wofi, btop, GTK themes)
6. Aplicaciones (VSCode, Git)
7. Script de instalación (install.sh)
8. Archivos a excluir (screenshots, datos locales, configs de otras plataformas)

## Estilo Elegido
Ligne claire (Hergé/Tintín style) - líneas limpias, colores planos, narrativo y educativo.

## Estructura del Cómic
- Portada: "Mi Configuración de Arch Linux"
- Página 1: El repositorio de dotfiles
- Página 2: El corazón del sistema (Hyprland, Ghostty, Zsh)
- Página 3: UI y herramientas (Waybar, Wofi, btop)
- Página 4: El script de instalación
- Página 5: Qué NO incluir (archivos a excluir)
