# Mi Configuración de Arch Linux - Dotfiles

## Contenido del Repositorio

Este repositorio contiene mis configuraciones personales de Arch Linux para un setup minimalista con Hyprland como window manager.

### Configs Esenciales (NECESARIAS)
- **hypr/** - Configuración de Hyprland (window manager)
- **ghostty/** - Terminal emulator
- **zsh/** - Shell configuration (zshrc, aliases)
- **wofi/** - Launcher de aplicaciones
- **waybar/** - Status bar
- **btop/** - Monitor del sistema
- **gtk-3.0/** y **gtk-4.0/** - Temas GTK
- **kitty/** - Terminal alternativo
- **zellij/** - Terminal multiplexer
- **bin/** - Scripts personales
- **git/** - Configuración de git
- **vscode/** - Configuración de VSCode (solo settings.json y keybindings.json)
- **install.sh** - Script de instalación automática

### Archivos NO necesarios (para excluir)
- screenshot.png (imagen, no config)
- agents/ (prompts de IA)
- aerospace/ (para macOS)
- iterm/ (solo macOS)
- cursor/ (binarios, no configs)
- vscode/globalStorage/, History/, workspaceStorage/ (datos locales de VSCode)
